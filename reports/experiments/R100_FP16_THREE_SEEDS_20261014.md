## Scientific scope

This experiment measures seed variation under one frozen R100 non-paper protocol. The complete-validation results below retain their original validation-only scope and must not be reported as test performance or as a SAM-Med3D comparison. The separate held-out follow-up is linked at the end of this report.

## Frozen protocol

| Field | Value |
|---|---|
| Dataset root | `data/processed/thebe_h5` |
| Precision | FP16 autocast (`float16_autocast`), not BF16 |
| Epochs | 100 per seed |
| Patch size | 128 |
| Training samples | 40 observed random patches per training file per epoch; 360 patches per epoch |
| Augmentation | Random axis-0 flip |
| Normalization | Per-patch z-score over observed voxels; axis reversal |
| Optimizer | Adam |
| Learning rate | 0.0001 |
| Loss | Ordinary BCE averaged over observed voxels |
| Validation seed | 1042 |
| Threshold selection | Best Dice on the complete validation volume using 2048 bins |
| Test use | Disabled during training; separate frozen test evaluation completed 2026-10-19 |
| Initialization/pretraining | Not established by the supplied audit; see each `run_config.json` |

Exact split membership and recorded configuration are preserved in each seed's `run_config.json`.

## Reliability notes

- The successful run used FP16 autocast, not BF16.
- The earlier nonfinite-gradient failure remains part of the numerical-stability record.
- PyTorch warned that `max_pool3d_with_indices_backward_cuda` has no deterministic CUDA implementation. Seeds were controlled, but strict bitwise reproducibility is not established.
- Held-out test evaluation completed separately on 2026-10-19; the validation metrics above retain their original meaning.
- No SAM-Med3D comparison exists yet.
