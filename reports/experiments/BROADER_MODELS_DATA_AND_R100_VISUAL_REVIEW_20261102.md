## What the linked paper actually says

Its Thebe Table I reports ODS 0.836 for FaultSeg3D, 0.868 for 3D Swin-UNETR with SimMIM, 0.870 for FaultSeg Swin-UNETR with SimMIM, 0.862 for 2D ImageNet Swin, 0.845 for 2D ImageNet DeepLabV3, 0.861 for SAM-b with adapter, and 0.879 for 2.5D SAM-h with adapter and augmentation. The paper's Fig. 3 visually compares faults on Thebe test crossline 150. The 3D models use **private unlabeled field data** for SimMIM pretraining, so the ODS 0.868–0.870 numbers are not architecture-only scores. The main comparison trains for **300 epochs**. The five-adjacent-slice result comes from an ablation; its 100-epoch table reports 5 better than 1, 3, or 7 slices. [Paper, Table I and Fig. 3](https://arxiv.org/html/2407.14121v1).

**Metric boundary:** its OIS chooses each image's best threshold on the evaluated images; its ODS chooses a single threshold on the evaluated dataset and averages image F1. Our 0.581257 R100 test number is pooled valid-voxel Dice with a **validation-frozen** threshold over the full test volume. The test images, aggregation, masking, and threshold selection differ. Therefore 0.879 versus 0.581 is not a measured 0.298 gain. We can reproduce OIS/ODS as an auxiliary descriptive metric from saved outputs, but primary local comparisons must keep the frozen protocol. [Paper metric definition](https://arxiv.org/html/2407.14121v1).

## Data worth acquiring for a new idea

| Source | What it provides | Best use and constraint |
|---|---|---|
| [GeoFWI3D author dataset](https://github.com/aaspip/geofwi3d) and [Zenodo](https://zenodo.org/records/20148778) | 10,000 CC BY 4.0 synthetic **96³** paired p-reflectivity `image3d.bin`, fault indices `fault3d.bin`, relative geological time `rgt3d.bin`, velocity and karst; larger 256³ set | Best **new joint fault+RGT experiment**. Start with one 1,000-volume archive, audit geometry and label balance. |
| [CIG-Bench datasets and predictors](https://github.com/douyimin/CIG-bench) | Synthetic structure/geobody data, field F3/USGS references, pretrained fault/RGT/property predictors | Independent cross-survey benchmark and auxiliary attributes. | [TerraNubis F3 Demo 2023](https://terranubis.com/datainfo/F3-Demo-2023) | Same F3 project lists seismic, porosity cube, similarity, fault-enhancement cube, steering, horizons and well logs | Promising **porosity/attribute** test after registration to a fault reference. Porosity cube is derived from a horizon/NN workflow; it is not a direct fault label. Check the displayed derivative-work terms before using or publishing a combined dataset. |
| [SS-UNETR Zenodo record](https://zenodo.org/records/13189298) | 25 GB archive described as code, trained model and datasets for seismic structural analysis | Candidate 3D pretrained Transformer. Inspect actual contents and task/weight compatibility before assuming the checkpoint transfers. |
| [Thebe Dataverse and processing code](https://github.com/anyuzoey/CNNforFaultInterpretation) | Public field fault labels and original split recipe | Shared in-domain benchmark for all controlled models. Keep the split and mask fixed. |

**Joint experiment with a genuinely new dataset:** acquire a small GeoFWI3D batch; compare equal-budget (A) fault-only pretraining, (B) fault+RGT multi-task pretraining, and (C) no pretraining, using the same lightweight backbone. Fine-tune each on Thebe train only. Select on the existing full validation grid; report test once after freezing. Record Dice, PR-AUC, per-block scores and fault continuity. A multitask gain over A, not only over C, would support the RGT hypothesis. A later F3 branch can compare seismic alone versus seismic plus similarity/fault-enhancement/porosity if volumes and labels align and their terms permit the use.

## The ~0.56 R100 experiment: what is now known

The single-seed frozen test Dice scores are **0.524797, 0.567466, 0.565498** for seeds 42–44. Their three-model probability ensemble scores **0.581257** test Dice and **0.620308** approximate test PR-AUC, from 2.303 billion scored voxels. The *completed* five-seed pilot reaches **0.597311 validation Dice**, versus **0.588951** for the original three-seed validation ensemble, a +0.008360 validation gain. There is no five-seed test score. [Frozen test report](../evaluation/r100_clean_frozen_test_20261019/report.md) · [Five-seed pilot](../evaluation/r100_seed_curve_5models_20261019/pilot_summary.json).

The five best checkpoint epochs are **95, 93, 95, 94, 89**. Fixed-subset validation PR-AUC is still materially higher in epochs 76–100 than 51–75 for every seed. For example seed 43 averages 0.5989 in epochs 51–75 and 0.6289 in 76–100. More training is a credible hypothesis, **not a measured improvement**. The existing trainer stores optimizer and RNG in `last.pt`, but refuses a resume if the planned epoch count changes; do not modify the frozen runs to extend them. A new 150-epoch run with the same initial seed and all other settings fixed is the clean first control. If its full-validation Dice/PR-AUC improve across both validation blocks, test 200 epochs and two more seeds. Use a new run directory and preserve the current 100-epoch result. A learning-rate schedule is a separate factor. [Training curve image](../evaluation/r100_test_visuals_20261102/training_curves.png).

The held-out test sections show coherent fault traces but also **wide probability bands, offset edges, and misses**; the patch-Dice distribution is broad. This motivates an *isolated* label-thickness/edge or BCE+Dice/foreground-sampling experiment, rather than assuming a bigger encoder alone will fix geometry. A single threshold change is insufficient to establish better structure. [Three-model test casebook](../evaluation/r100_test_visuals_20261102/casebook.png) · [seed-43 test casebook](../evaluation/r100_test_visuals_20261102/seed43_casebook.png) · [full-test patch/PR plot](../evaluation/r100_test_visuals_20261102/test_summary.png) · [visual selection manifest](../evaluation/r100_test_visuals_20261102/manifest.json).

The casebooks use fixed full-test tiles from three x slabs (0, 256, 512), each the median-positive fault tile among tiles with more than 1.5 million valid voxels in its slab; the displayed x slice maximizes reference fault pixels within that tile. This is a **qualitative, label-guided display choice**, not test-based model or threshold selection. The images come from saved best checkpoints with the previously frozen thresholds. The selected tiles are not an estimate of overall performance; the full-test report remains authoritative. Reproduce with [`scripts/visualize_r100_frozen_test.py`](../../scripts/visualize_r100_frozen_test.py).

## Concrete next run order

1. **Running architecture control:** train FaultSegV3 from random initialization with the same 128³ Thebe tiles, crop sequence, observed-voxel mask, 360 patches/epoch, masked BCE, optimizer, seed, checkpoint rule, and 150-epoch budget as the parallel R100 control. This isolates limited downsampling and the full-resolution branch; [selection and live run record](R100_150_PARALLEL_HIGHRES_SELECTION_20261102.md).
2. **Conditional loss/context ablation:** if high resolution fixes overlap but leaves wide or broken surfaces, test a 3D boundary-distance loss and then a topology/continuity loss as separate factors. If it does not help, move to the already preflighted MONAI Swin-UNETR context control; [saved preflight evidence](../evaluation/swinunetr_training_preflight_20261102.json).
3. **First new-data joint run:** GeoFWI3D no pretraining versus fault-only versus fault+RGT pretraining, then matched Thebe fine-tuning with the encoder selected by the architecture control.
4. **Systems and interactive follow-ups:** 2.5D five-slice U-Net/Swin, nnU-Net, and then a seismic SAM adapter or FaultSeg Swin-UNETR reproduction if the factor-level controls justify the engineering cost.

The matched R100, FaultSegV3, and SwinUNETR 150-epoch runs are active; they do not have final scores yet. Existing R100/FaultEdgeFormer training and the stated zero-shot evaluations are complete. No completed trained Swin, 2.5D, nnU-Net, seismic SAM, or GeoFWI3D score exists yet.
