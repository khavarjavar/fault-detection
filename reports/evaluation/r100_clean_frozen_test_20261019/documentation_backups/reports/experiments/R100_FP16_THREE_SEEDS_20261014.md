## Scientific scope

This experiment measures seed variation under one frozen R100 non-paper protocol. All metrics below are complete-validation metrics. They are not held-out test results and must not be reported as test performance or as a SAM-Med3D comparison.

## Frozen protocol

| Field | Value |
|---|---|
| Dataset root | `data/processed/thebe_h5` |
| Precision | FP16 autocast (`float16_autocast`), not BF16 |
| Epochs | 100 per seed |
| Patch size | 128 |
| Training samples | 40 observed random patches per training file per epoch; 360 patches per epoch |
| Augmentation | Random axis-0 flip |
| Normalization | Per-patch z-score over observed voxels; axis reversal |
| Optimizer | Adam |
| Learning rate | 0.0001 |
| Loss | Ordinary BCE averaged over observed voxels |
| Validation seed | 1042 |
| Threshold selection | Best Dice on the complete validation volume using 2048 bins |
| Test use | Disabled; no test evaluation |
| Initialization/pretraining | Not established by the supplied audit; see each `run_config.json` |

Exact split membership and recorded configuration are preserved in each seed's `run_config.json`.
