## Correct interpretation

These results measure how a model trained only on synthetic FaultSeg3D transfers to real Thebe without training or adaptation. They do not measure a model trained using real data.

Scores apply only to observed Thebe seismic voxels. Exact-zero blank/muted regions were excluded using a seismic-only mask.

Thebe label thickness may differ from FaultSeg3D label thickness, so this must be documented when comparing datasets.

## No-data-label caveat

Some positive fault annotations extend into exact-zero seismic areas. They were excluded because those locations contain no observable seismic input. The count and percentage are reported above rather than hidden.
